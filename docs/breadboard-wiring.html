Breadboard Wiring Guide

CV Axle Controller — Arduino Pro Micro + 2x JH-D400X-R4 Joysticks

Arduino Pro Micro

Qty: 1

ATmega32U4, 5V/16MHz. Native USB HID — the computer sees it as a keyboard. Micro-USB or USB-C depending on variant.

JH-D400X-R4 Joystick

Qty: 2

4-axis: X (left/right), Y (up/down), Z (twist barrel), pushbutton. 10K pots, 5V. We use X for coarse, twist (Y) for fine.

Blue LEDs

Qty: 2 + 220 ohm resistors

Fine mode indicators. One per joystick. Lights up when twist/fine axis is active.

Green LED

Qty: 1 + 220 ohm resistor

Lock indicator. ON when controller is active (unlocked). OFF when locked.

Toggle Switch (SPST)

Qty: 1

Lock/enable switch. Connects D4 to GND when flipped. Uses internal pullup — no external resistor needed.

Breadboard + Jumpers

Half-size breadboard, ~20 jumper wires

Standard solderless breadboard. The Pro Micro straddles the center channel. Joysticks connect via jumper wires to analog/digital pins.

Breadboarding Notes

  • The Pro Micro straddles the breadboard center channel. Pin labels are on the bottom — flip it to verify pin numbers before wiring.
  • Use the breadboard power rails for 5V and GND. Run one jumper from Pro Micro VCC to the + rail, one from GND to the - rail.
  • Both joysticks share the same 5V and GND rails. Run power and ground to each joystick from the breadboard rails.
  • LEDs need 220 ohm current-limiting resistors. Wire: Arduino pin → resistor → LED anode (long leg) → LED cathode (short leg) → GND rail.
  • The joystick buttons and lock switch use INPUT_PULLUP in firmware — they connect the pin to GND when pressed/flipped. No external resistors needed.
  • The JH-D400X-R4 has 5 wires: VCC, GND, VRx, VRy, SW. The twist barrel is mapped to VRy.
  • After wiring, upload the firmware and open Serial Monitor at 115200 baud. Type RAW to see live analog readings — verify joysticks are centered around 512.
  • Type STATUS to see current mode, deadzones, and lock state. Type HELP for all commands.
  • Hold a joystick button for 3 seconds to auto-calibrate its deadzone. The fine LED will blink during calibration.
  • The lock switch disables all keystrokes when engaged. The green LED turns off to indicate locked state.

Testing Checklist

  • Upload firmware → Serial Monitor at 115200 → type STATUS — should show "Proportional" mode, lock OFF
  • Push Joystick 1 left/right → see A/D keystrokes in a text editor (or Serial Monitor shows them)
  • Twist Joystick 1 barrel → see Q/E keystrokes (fine mode), blue LED 1 lights up
  • Push Joystick 2 left/right → see J/L keystrokes
  • Twist Joystick 2 barrel → see U/O keystrokes, blue LED 2 lights up
  • Flip lock switch → green LED off, all keystrokes stop
  • Hold Joystick 1 button 3 seconds → LED blinks → "Calibrated" in Serial Monitor
  • Type RAW → verify analog values near 512 when joysticks are centered
  • Open the Axle Measurement web app → verify joystick moves the measurement lines
