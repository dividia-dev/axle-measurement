Component Legend

Joystick 1 — JH-D400X-R4, Line 1 coarse (X) + fine (twist)
Joystick 2 — JH-D400X-R4, Line 2 coarse (X) + fine (twist)
Fine LED 1 — Blue, fine mode active + dead zone/centering calibration for Joystick 1
Fine LED 2 — Blue, fine mode active + dead zone/centering calibration for Joystick 2
Lock LED — Dual-color: green = active, red = locked (single bi-color LED)
Flip Switch — Micro toggle, master lock/enable for all input
USB-C — Power + HID keyboard to computer
Rubber Feet — Anti-slip pads on bottom
Approximate dimensions: 180mm W × 120mm D × 35mm H (body only, ~55mm with joystick sticks)
Enclosure designed for FDM 3D printing — snap-fit or screw-closed halves
Internal cavity houses Arduino Pro Micro, wiring, and resistors
Vent slots on rear for passive cooling — optional depending on operating environment
