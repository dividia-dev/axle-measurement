Dividia Development

Axle Measurement System

Camera-based axle spacing measurement with Federal Bridge Formula B weight calculations. Built for industrial scale houses and FL DOT overweight permit verification.

Launch Interactive Demo
🎯

Precision Measurement

Two movable reference lines on live video feed. Calibrate once with a known distance, then measure any axle spacing. Coarse and fine adjustment modes for pixel-level accuracy.

⚖️

Bridge Formula Calculator

Instant max allowable weight using Federal Bridge Formula B (23 USC 127). Florida-specific special vehicle caps for dump trucks, concrete mixers, waste, and fuel transport.

📸

Screenshot Evidence

Save measurements with annotated screenshots showing line positions, distance, axle count, and weight data. Full measurement history with view and download.

🏭

Scale House Integration

Designed for cement plant and aggregate facility scale houses. Connects to existing NVR infrastructure via WebRTC for live camera feeds.

🕹️

Hardware Controller

USB HID controller with dual joysticks for hands-free line adjustment. Arduino Pro Micro with twist potentiometers. Keyboard fallback always available.

📋

Permit Verification Planned

FL DOT overweight permit lookup via the PAS portal. Not yet implemented. May require an FDOT account and web scraping to retrieve permit data, as no public API is currently available.

How It Works

1

Calibrate

Align measurement lines to a known reference distance in the camera view

2

Measure

Position lines on the first and last axle of the vehicle using keyboard or joystick

3

Calculate

Bridge Formula B computes max allowable weight based on axle count and spacing

4

Record

Save measurement with annotated screenshot for compliance records
