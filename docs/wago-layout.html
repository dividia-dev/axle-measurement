Build Steps

1. Pro Micro Prep

  • Solder 2× 12-pin female headers to perfboard at correct spacing
  • Flip board — solder a 4-5 inch wire to the underside of each USED pin
  • Used pins: D2, D3, D4, D5, D6, D7, D8, D9, A0, A2, VCC, GND (12 wires)
  • Strip ~8mm at free end of each wire for Wago insertion
  • Label each wire with its pin name (tape flag or heat-shrink)

2. Resistor Prep

  • Solder a short wire (~3 inches) to each lead of both 220Ω resistors
  • Heat-shrink the solder joints
  • Label: R1-in, R1-out, R2-in, R2-out
  • R1 is for Fine LED 1 (D6), R2 is for Fine LED 2 (D7)

3. Wago Assembly

  • Start with GND bus — connect GND-A and GND-B with a bridge wire
  • Add VCC bus (3-port — Pro Micro VCC + J1 VCC + J2 VCC)
  • Connect signal Wagos one at a time, testing each with a multimeter
  • Resistor Wagos: D6 → R1-in Wago, R1-out → FL1+ Wago

4. Testing Order

  • Plug in Pro Micro via USB — verify 5V on VCC bus
  • Connect J1 only — test coarse movement
  • Add J1 button — test fine toggle
  • Repeat for J2
  • Add LEDs one at a time
  • Add lock toggle + recal last
